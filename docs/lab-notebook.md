# Lab Notebook

Running record of what was built, what was run, and what the numbers were.
One entry per week, appended on the last working day.

This file is the raw material for the paper's methods and results sections.
Write the entry even in weeks where nothing worked — a negative result recorded
in September is evidence in December, and a failed approach that isn't written
down gets silently repeated.

**Entry format:**

```
## W<n> · <date range> · <one-line summary>

**Built:** what shipped this week
**Ran:** the experiment and its configuration (circuits, shots, backend, seeds)
**Result:** the number, with its error bar
**Expected:** what you predicted before running it
**Surprised by:** anything that contradicted the prediction
**Next:** what this changes about the following week
```

The **Expected** line matters more than it looks. Writing the prediction down
*before* seeing the result is what separates a finding from a rationalization,
and reviewers can tell the difference.
